# ByJTT Design

**Research, design, build, and validate excellent digital products with AI.**

ByJTT Design is the intelligence and quality layer behind `design.byjtt.com`.

## Design Studio vertical slice

The first browser product lives in [`app/`](./app/). It proves the core loop with a real local-service website:

**Describe → Design → Direct → Validate → Publish → Remix**

The Studio includes a live responsive website preview, plain-language iteration, evidence checks, provenance, explicit publication and a Resource Library view.

This first slice uses deterministic transformations so the product contract can be tested before connecting a production model provider. The model adapter is deliberately replaceable.

Agent principle

Creation and evaluation are separate jobs. An agent should know what it was asked to change, what it is allowed to change, what evidence exists and what remains uncertain.

Action lifecycle

Make state visible.

A machine suggestion is not the same thing as an executed, verified or human-approved action.

Suggested → Generated → Inspected → Verified → Executed → Human-approved

Use the strongest claim supported by the evidence actually available. Preserve user control for consequential actions and prefer reversible operations when practical.

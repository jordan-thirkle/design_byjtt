Production quality

Production is the source of truth.

Final confidence should come from the implemented product: real viewports, real content, interaction and state coverage, accessibility, performance and regression evidence — not a screenshot alone.

For agents: prefer explicit intent over screenshot inference.

Use structured contracts, requirements and evidence. Important autonomous changes should expose rationale, uncertainty and changed scope.

# ADR 0005 — v0.1 interoperable design-integrity foundation

- **Status:** Accepted
- **Date:** 2026-08-27

## Context

Phase 1 already established a verified benchmark harness. The product also needs portable foundations for evidence, decisions, contracts, context compilation, observatory signals and conformance without prematurely becoming another generator or local-model runtime.

## Decision

1. Keep this repository and `design.byjtt.com` canonical.
2. Adopt JSON Schema 2020-12 for v0.1 records and DTCG 2025.10 for tokens.
3. Compile canonical sources into a generic Design Context Package before applying target-specific adapters.
4. Treat Claude `/design`, CommandCode `/design`, Figma, Stitch, v0, Lovable, Replit and Superdesign as adapters or benchmark targets, not dependencies.
5. Prioritize GPT-5.6 Sol Light, CommandCode and free/open/local models; paid Claude/Gemini subscriptions are not required.
6. Keep the future assistant retrieval-first and inference-backend-agnostic.
7. Separate hard constraints, creative territory and unresolved questions in machine-readable contracts.

## Consequences

- Provider churn does not redefine product intent.
- Deterministic validation remains possible without an AI model.
- Adapters can lose presentation detail but may not weaken constraints or invent unknowns.
- Real-world validation is required before any v0.1 schema becomes canonical.
